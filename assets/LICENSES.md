# Asset licences

Every asset file in this repository, where it came from and under what licence. Add a row when
you add an asset file. Do not add an asset whose own page does not clearly state CC0 (or SIL OFL
for fonts). The reasons are in Appendix F of the design document.

All files are unmodified copies of the originals; only the file names changed.

DSEG and Orbitron have a Reserved Font Name. A changed version of either font (subset, converted
to another format, edited) must not keep that name, so ship these files as they are.

`Doto-variable.woff2` and `Orbitron-variable.ttf` are variable fonts: one file covers every weight
(Doto 100 to 900 plus a roundness axis, Orbitron 400 to 900).
